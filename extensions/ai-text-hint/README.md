# AI Text Hint (Chrome MV3)

Analyzes **text on web pages** only. Uses on-device pattern signals (phrases, sentence uniformity). **Not** a certified AI detector.

## Install

`chrome://extensions` → Developer mode → Load unpacked → this folder.

## Use

1. Open a blog/article page.
2. Click the extension → **Analyze page article** or select text first → **Analyze selection**.

## Store listing

Describe as *informational text signals*, not *AI detection guaranteed*.
