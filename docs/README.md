# Public pages for App Store URLs

Host these files with **GitHub Pages** (one-time setup):

1. On GitHub: **space-wellness** → **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main**, folder: **/docs** → Save

After a minute or two, use these URLs in App Store Connect.
